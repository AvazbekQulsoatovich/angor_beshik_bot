# Angor Beshik Bot

Bu loyiha Angor Beshiklari do'koni uchun yaratilgan Telegram bot.

## Texnologiyalar
- Python 3.11+
- Aiogram 3.x
- aiosqlite (SQLite)

## Ishga tushirish
1. `requirements.txt` o'rnating: `pip install -r requirements.txt`
2. `.env` faylini yarating va `BOT_TOKEN` hamda `ADMIN_IDS` ni kiriting.
3. `python main.py` orqali botni ishga tushiring.
